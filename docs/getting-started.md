Everything here assumes NixOS with flakes enabled and UEFI boot. You'll
need `mkpasswd` once for a password hash - `nix run nixpkgs#mkpasswd`.

## Getting started

A host is three files under `modules/hosts/<name>/`:

| File | What it is | Tracked? |
| --- | --- | --- |
| `Host.nix` | apps, theme, timezone, bootloader | yes |
| `_hardware.nix` | your disks, generated by NixOS | no - gitignored |
| `_user.nix` | who logs in, password hash, API keys | no - gitignored |

The two gitignored ones don't exist until you make them, and the build
refuses to evaluate without them on purpose - a public repo shouldn't
carry someone's real disk UUIDs or password hash.

### Trying it on the existing host

```bash
git clone https://github.com/aayush2622/Vayori-Rice.git vayori
cd vayori
cp modules/hosts/Diablo/_hardware.nix.example modules/hosts/Diablo/_hardware.nix
cp modules/hosts/Diablo/_user.nix.example modules/hosts/Diablo/_user.nix
$EDITOR modules/hosts/Diablo/_user.nix   # at least pick a username
sudo nixos-rebuild switch --flake path:.#Diablo
```

Any user without a `hashedPassword` gets `changeme` as an initial
password - run `passwd` after the first login.

### Making it your own host

1. `cp -r modules/hosts/Diablo modules/hosts/<yourhostname>`
2. `sudo nixos-generate-config --show-hardware-config > modules/hosts/<yourhostname>/_hardware.nix`
   (drop the Nvidia/Optimus block unless you're also on one)
3. `cp .../<yourhostname>/_user.nix.example .../<yourhostname>/_user.nix`
   and fill it in - `mkpasswd -m sha-512` for the hash
4. Edit `Host.nix` - rename the host, flip the apps you want on or off,
   fix timezone/locale/bootloader
5. `sudo nixos-rebuild switch --flake path:.#<yourhostname>`

### Why `path:.#Diablo` and not `.#Diablo`

A bare flake ref resolves through git's *tracked files* view, which makes
`_hardware.nix` and `_user.nix` look missing even though they're sitting
right there on disk. `path:` reads the real directory as-is. This trips
up everyone exactly once.

### Turning apps on and off

Every module under `modules/apps/` is one boolean in `Host.nix`:

```nix
vayori.apps = {
  Vscode.enable = true;
  Gaming.enable = true;
  Rust.enable = false;
};
```

Type `vayori.apps.` in an editor with Nix LSP support and every available
app shows up by name. A typo is a real evaluation error, not a silently
ignored entry. Leaving one `false` rather than deleting it keeps it
visible that the app exists and is simply off.
